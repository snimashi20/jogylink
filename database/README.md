# B1 Central database

PostgreSQL single source of truth for products, batches, shops, producers, orders, payments and movements. Migrations live in migrations/.

- Rollout wave: 1
- Solves: All
- Spec: [docs/architecture.md](../docs/architecture.md)

Migrations are generated by Drizzle from `packages/db/src/schema` (`pnpm --filter @jogylink/db db:generate`)
and applied with `db:migrate`. Do not edit generated SQL by hand: change the schema and generate a new one.
